# Hospital Management System

A web-based hospital management system built with ASP.NET MVC and C#. It keeps patient, doctor, appointment, and billing records in one place, so hospital staff can find and update information quickly.

## Features

- Register and manage patient records
- Manage doctor profiles and departments
- Book, edit, and cancel appointments
- Generate and track bills
- Search patients and appointments
- Login system for staff

## Tech Stack

- C#
- ASP.NET MVC
- SQL Server
- Entity Framework
- HTML, CSS, Bootstrap

## Getting Started

### Requirements

- Visual Studio 2019 or later
- .NET Framework 4.7.2 or later
- SQL Server (Express edition works fine)

### Setup

1. Clone the repository:

```
   git clone https://github.com/Salam88-as/Hospital-Management-System.git
```

2. Open the solution file (`.sln`) in Visual Studio.
3. Open `Web.config` and update the connection string to match your SQL Server.
4. Restore NuGet packages (right-click the solution, then **Restore NuGet Packages**).
5. Build the project and press **F5** to run it.

## Project Structure

```
Controllers/   Handles requests and application logic
Models/        Data models and database context
Views/         Pages shown to the user
Content/       CSS and images
Scripts/       JavaScript files
```
